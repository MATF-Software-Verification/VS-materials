\subsubsection{Gradle}\label{gradle}

Da bi se Gradle instalirao, neophodno je na sistemu imati verziju JDK-a veću od 8. Gradle se potom instalira kroz paket \texttt{gradle} za većinu popularnih Linux distribucija. Alternativno, moguće je preuzeti \href{https://gradle.org/releases}{unapred spremne Gradle artefakte} i ručno instalirati Gradle. Primeri pretpostavljaju da je izvršiva datoteka (ili alias) \texttt{gradle} dostupna na \texttt{PATH}-u i pokreće Gradle alat.

Neobavezno za ovaj primer, za laku organizaciju u okruženju sa više različitih JDK verzija, može se koristiti alat \href{https://sdkman.io/}{SDKMAN}. Gradle se može instalirati korišćenjem SDKMAN-a:

\begin{minted}{bash}
$ sdk install gradle <verzija>
\end{minted}

Na primer:

\begin{minted}{bash}
$ sdk install gradle 7.5.1
\end{minted}
