\subsubsection{xUnit / NUnit}\label{xunit--nunit}

\texttt{xUnit} i \texttt{NUnit} se jednostavno instaliraju sa NuGet repozitorijuma (\href{https://www.nuget.org/packages/xUnit}{xUnit}, \href{https://www.nuget.org/packages/xUnit}{NUnit}) ili uz pomoć IDE-a, ili kroz komande:

\begin{minted}{bash}
$ dotnet add package xunit --version 2.4.2
$ dotnet add package NUnit --version 3.13.3
\end{minted}

Alati koji se isporučuju kao lokalni .NET alati obnavljaju se iz direktorijuma koji sadrži manifest \texttt{.config/dotnet-tools.json}. Primer za pokrivenost koda koristi \texttt{dotnet-coverage}, pa je za tu vežbu dovoljno pokrenuti:

\begin{minted}{bash}
$ dotnet tool restore
\end{minted}
