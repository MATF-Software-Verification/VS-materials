\subsubsection{Valgrind}\label{instalacija-valgrind}

Valgrind se na većini Linux distribucija može instalirati kroz paket \texttt{valgrind}. Npr., za Ubuntu:

\begin{minted}{bash}
$ sudo apt-get install valgrind
\end{minted}

Za grafički prikaz izveštaja nekih Valgrind-ovih alata može se koristiti program \emph{KCachegrind}. Instalacija, npr., za Ubuntu:

\begin{minted}{bash}
$ sudo apt-get install kcachegrind
\end{minted}
