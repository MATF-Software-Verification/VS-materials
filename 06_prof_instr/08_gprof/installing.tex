\subsubsection{gprof}\label{instalacija-gprof}

\texttt{gprof} je deo GNU binutils paketa na većini Linux distribucija. Za prevođenje primera potreban je i GCC.

\begin{minted}{bash}
$ gcc --version
$ gprof --version
\end{minted}

Na Debian/Ubuntu sistemima tipično je dovoljno instalirati razvojne alate:

\begin{minted}{bash}
$ sudo apt-get install build-essential binutils
\end{minted}
