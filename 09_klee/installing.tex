\subsubsection{KLEE}\label{klee}

KLEE se može instalirati prateći uputstva na zvaničnoj \href{https://klee.github.io/getting-started/}{stranici}. Preporučeno je koristiti Docker kontejner:

\begin{minted}{bash}
$ docker pull klee/klee:3.0
$ docker run --rm -ti --ulimit='stack=-1:-1' klee/klee:3.0
\end{minted}
