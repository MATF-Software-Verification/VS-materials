\subsection{C\# - Moq}\label{c---moq}

\href{https://github.com/moq/}{Moq} (izgovara se \emph{Mock-you} ili jednostavno \emph{Mok}) je vodeći radni okvir za pisanje objekata imitatora u .NET ekosistemu. Dizajniran je da bude veoma praktičan i bezbedan. Neke od osobina:

\begin{itemize}
\tightlist
\item
  Jako tipiziran (ne koriste se niske za definisanje očekivanja, povratne vrednosti metoda su specifični tipovi a ne opšti \texttt{object} tip)
\item
  Jednostavni idiomi - konstrukcija imitatora, podešavanje ponašanja imitatora, očekivanja
\item
  Granularna kontrola ponašanja imitatora
\item
  Imitira i interfejse i klase
\item
  Presretanje događaja nad imitatorima
\end{itemize}

U datoteci \texttt{MockExamples.cs} imamo definicije nekoliko interfejsa i klasa:

\begin{itemize}
\tightlist
\item
  \texttt{IBookService} - predstavlja interfejs servisa koji koristimo da dovučemo informacije o knjigama na osnovu kategorije ili ISBN
\item
  \texttt{IEmailSender} - predstavlja interfejs servisa koji koristimo da pošaljemo e-mail
\item
  \texttt{AccountsService} - koristi navedene servise
\item
  \texttt{SampleAccountsServiceTests} - testovi za \texttt{AccountsService}
\end{itemize}

Pošto \texttt{IBookService} može na proizvoljan način da dovlači informacije o knjigama (REST-ful API, baza podataka itd.), jasno je da ne želimo da je testiramo direktno. Štaviše, naši testovi se tiču \texttt{AccountsService} klase, a ne klasa koje ona koristi, dakle podrazumevamo da se implementacije \texttt{IBookService} i \texttt{IEmailSender} ispravno ponašaju. Tu pretpostavku implementiramo pomoću objekata imitatora.

Posmatrajmo klasu \texttt{SampleAccountsServiceTests}. Naredni primer prikazuje jednostavan idiom za korišćenje Moq radnog okvira:

\begin{minted}{csharp}
public void GetAllBooksForCategory_returns_list_of_available_books()
{
    // 1
    var bookServiceStub = new Mock<IBookService>();

    // 2
    bookServiceStub
        .Setup(x => x.GetBooksForCategory("UnitTesting"))
        .Returns(new List<string> {
            "The Art of Unit Testing",
            "Test-Driven Development",
            "Working Effectively with Legacy Code"
        });

    // 3
    var accountService = new AccountService(bookServiceStub.Object, null);
    var result = accountService.GetAllBooksForCategory("UnitTesting");

    // 4
    Assert.Equal(3, result.Count());
}
\end{minted}

Sličan imitator možemo napisati i za \texttt{IEmailService}, ukoliko želimo da testiramo metod \texttt{SendEmail}:

\begin{minted}{csharp}
public void SendEmail_sends_email_with_correct_content()
{
    // 1
    var emailSenderMock = new Mock<IEmailSender>();

    // 2
    var accountService = new AccountService(null, emailSenderMock.Object);
    // 3

    accountService.SendEmail("test@gmail.com", "Test - Driven Development");
    // 4
    emailSenderMock.Verify(
        x => x.SendEmail(
            "test@gmail.com",
            "Awesome Book",
            $"Hi,\n\nThis book is awesome: Test - Driven Development"
        ),
        Times.Once
    );
}
\end{minted}

Moguće je modelirati višestruke pozive. U primeru koji sledi zadajemo povratne vrednosti za prva četiri poziva metoda \texttt{GetISBNFor}, poziv metoda \texttt{GetBooksForCategory} podešavamo tako da baca izuzetak:

\begin{minted}{csharp}
bookServiceStub
    .SetupSequence(x => x.GetISBNFor(It.IsAny<string>()))
    .Returns("0-9020-7656-6")   //returned on 1st call
    .Returns("0-9180-6396-5")   //returned on 2nd call
    .Returns("0-3860-1173-7")   //returned on 3rd call
    .Returns("0-5570-1450-6")   //returned on 4th call
    ;

bookServiceStub
    .Setup(x => x.GetBooksForCategory(It.IsAny<string>()))
    .Throws<InvalidOperationException>();
\end{minted}

Za poznavaoce asinhronog šablona zasnovanog na zadacima (engl. \href{https://learn.microsoft.com/en-us/dotnet/standard/asynchronous-programming-patterns/task-based-asynchronous-pattern-tap}{Task-Based Asynchronous Pattern, skr. TAP}) u programskom jeziku C\#, mogu od značaja biti i asinhroni primeri korišćenja Moq radnog okvira:

\begin{minted}{csharp}
httpClientMock
    .Setup(x => x.GetAsync(It.IsAny<string>()))
    .ReturnsAsync(true);
\end{minted}
