\subsubsection{Primer: Sudoku aplikacija}\label{sudoku-java-debug-primer}

Ovaj primer sadrži konzolnu Java aplikaciju za igru Sudoku i jedan JUnit test koji zamenjuje standardni ulaz i izlaz. Primer je pogodan za vežbanje debagovanja aplikacije koja čita komande od korisnika, jer se ista putanja može pokrenuti ručno ili kroz test.

Ulazna tačka aplikacije je klasa \texttt{com.company.Main}. Metod \texttt{play} prikazuje meni, učitava izbor korisnika i poziva klase koje menjaju stanje table. Za debagovanje je korisno postaviti tačke prekida na mestima gde se učitava izbor težine, unosi polje i proverava rezultat poteza.

JUnit test priprema veštački ulaz preko \texttt{ByteArrayInputStream} i hvata izlaz preko \texttt{ByteArrayOutputStream}. Time se interaktivna aplikacija pretvara u ponovljiv test slučaj.

\codefile{test/test/MainTest.java}{java}

Tipičan tok vežbe:

\begin{itemize}
\tightlist
\item
  pokrenuti test \texttt{testPlay} iz IDE okruženja u debug režimu;
\item
  pratiti vrednosti \texttt{usrChoice}, \texttt{location} i \texttt{parseAddReturn};
\item
  ući u poziv \texttt{parseAdd} i proveriti kako se tekstualna oznaka polja prevodi u koordinate table;
\item
  promeniti simulirani ulaz u testu i proveriti kako aplikacija reaguje na neispravnu komandu.
\end{itemize}

Pošto test menja globalne tokove \texttt{System.in} i \texttt{System.out}, metode \texttt{setUp} i \texttt{restoreSystem} moraju da vrate originalno stanje posle svakog testa. U suprotnom se greška može preneti na sledeći test.
